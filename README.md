# 마나 마켓

이세계 왕국의 거래소에서 **하루 한 번** 공시와 소문을 읽고 가상 화폐로 주식을 거래하는 느긋한 웹게임입니다.
실제 돈·시세와 무관한 순수 가상 게임이며 투자 조언이 아닙니다. 설계 결정의 전체 기록은 [`CLAUDE.md`](./CLAUDE.md)에 있습니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:5173 (폰 세로 화면, 데스크톱은 폰 틀로 보입니다)
npm test             # 엔진 + 웹 + 서버 Vitest
npm run typecheck && npm run build
npm run e2e          # 처음부터 끝까지 브라우저 시험(접근성·프레임 포함, 크롬 필요)
npm run server       # (개발용) 2단계 서버 뼈대, 포트 8787 — 공개 금지
npm run sim -- --days 300 --seeds 60   # 시장 시뮬레이션 요약(밸런스 확인)
```

## 구성

| 위치 | 내용 |
|---|---|
| `packages/engine` | 순수 TypeScript 시장 엔진: 시드 기반 가격 갱신, 이벤트(공시·소문·여진), 시장 국면(호황·버블·폭락), 분기 배당, 판타지 달력(건국력) |
| `apps/web` | React + Vite + Tailwind + Zustand. 코드로 그린 도트 월드(아이소메트릭), 길드·성·NPC·히로인, 거래 UI, 업적 |
| `apps/server` | 2단계 서버 뼈대(개발용, 인증 없음): 서버 시세 체결·정산·순위. 웹의 서버 모드는 개발 빌드에서만 보입니다 |
| `apps/web/art-source` | 사용자가 만든 일러스트 원본(히로인 초상화 등). `scripts/prepare-*.py`가 게임용 WebP로 변환 |

## 화면 구성과 조작
- 아래 메뉴: 거래 · 소식 · **생활** · 달력(가운데) · 자산 · 시세 · 내 정보 (키보드 1~6, C 달력, P 내 정보, Esc 닫기).
- **생활** 탭: 오늘의 모험 목표, 오늘 할 일과 "걸어가기"(길 안내), 활동(채집·낚시·던전)과 작업대, 마을 가꾸기, 내 상점, 인연, 탈것, 도감.
- 걷기: 방향키·WASD·땅 클릭(터치는 가상 패드). Enter = 길드 거래, E = 말걸기·채집·낚시·던전.

## 핵심 규칙

- 시간은 현실과 나란히 흐릅니다: 하루 = 현실의 하루, 한국 시각 자정에 새 하루가 시작되고 시세는 하루 종일 15분마다 움직입니다.
- 시장은 저장하지 않고 `(세계 시드, 날짜)`로 언제든 같은 모습이 계산됩니다. 모든 플레이어가 같은 시장을 봅니다.
- 공시는 확정된 사실, 소문은 틀릴 수도 있는 정보입니다. 가격 영향은 규칙 엔진이 계산하고 LLM은 관여하지 않습니다.
- 1단계는 서버·로그인이 없습니다(저장은 브라우저 localStorage, 프로필의 "저장 옮기기"로 백업).

## 배포(정적)

`npm run build`가 만드는 `apps/web/dist`를 정적 호스팅(Cloudflare Pages, Vercel, Netlify 등)에 올리면 됩니다. 서버·환경 변수가 필요 없고 서비스 워커로 오프라인에서도 열립니다. 이벤트·가격 규칙을 바꾸면 `WORLD_VERSION`과 골든 테스트를 함께 갱신합니다(`CLAUDE.md` 참고).
