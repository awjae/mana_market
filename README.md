# 마나 마켓

중세 판타지 세계의 가상 증권거래소에서 **가상 화폐(마나)** 로 주식을 거래하고, 마을 밖에서는 채집·낚시·던전·인연·마을 가꾸기를 즐기는 웹게임입니다.
하루에 한 번 접속해 공시와 소문을 읽고 판단하는 느긋한 루프를 중심에 둡니다.

> 가상의 세계와 가상 화폐로 즐기는 게임입니다. 실제 돈·실제 시세와 전혀 관계없고, 어떤 내용도 투자 조언이 아닙니다.

설계 결정과 규칙의 전체 기록은 [`CLAUDE.md`](./CLAUDE.md)에 있습니다(코드를 고치기 전에 읽어 주세요).

## 특징

- **모두가 같은 시장:** 시세는 저장하지 않고 `(세계 시드, 날짜, 15분 슬롯)`으로 계산합니다. 같은 시각이면 누구나 같은 가격을 봅니다.
- **공시는 사실, 소문은 불확실:** 가격 영향은 규칙 엔진이 계산하고(LLM 관여 없음), 대사와 안내에는 전망·매매 권유가 없습니다.
- **주식:** 길드 10곳(5개 업종), 시장 국면(평온·호황·버블·폭락), 분기 배당, 지정가 예약 주문과 가격 알림, 대출(마나 은행).
- **생활 콘텐츠(마나 수입 상한 있음, 시세와 무관):** 채집과 낚시 미니게임, 20층 턴제 던전(몬스터 일러스트·도감), 재료 제작, 모험가 등급과 업적, 입문 과제·오늘의 목표·주간 도전·축제 이벤트.
- **엔드게임:** 마을 가꾸기·확장, 내 상점(수입 없음), 히로인 5명과의 인연(평생 1명), 탈것.
- **월드:** 코드로 그린 도트 아이소메트릭 마을(캔버스 한 장), NPC와 날씨·계절·축제, 길 찾기 걷기와 "걸어가기" 안내.
- **접근성:** 키보드·터치·모션 감소·쉬운 모드를 지원하고, axe 위반 0을 e2e로 확인합니다.

## 실행

Node 20 이상(개발은 22)이 필요합니다.

```bash
npm install
npm run dev          # http://localhost:5173 (모바일 세로 화면, 데스크톱은 폰 틀로 보입니다)
```

| 명령 | 설명 |
|---|---|
| `npm test` | 엔진 + 웹 + 서버 Vitest |
| `npm run typecheck` | 모든 워크스페이스 타입 검사 |
| `npm run build` | 웹 빌드(`apps/web/dist`) |
| `npm run e2e` | 처음부터 끝까지 브라우저 시험(접근성·프레임 포함, Chromium 필요) |
| `npm run sim -- --days 300 --seeds 60` | 시장 시뮬레이션 요약(밸런스 확인) |
| `npm run server` | (개발용) 서버 뼈대, 포트 8787 — **공개 금지** |

`npm run e2e`는 개발 서버를 5199 포트로 직접 띄웁니다. Playwright용 Chromium이 없으면 `npx playwright install chromium` 후 실행하거나, `E2E_CHROMIUM`으로 실행 파일을 지정하세요.

## 화면 구성과 조작

- 아래 메뉴: 거래 · 소식 · **생활** · 달력(가운데) · 자산 · 시세 · 내 정보 (키보드 1~6, C 달력, P 내 정보, Esc 닫기).
- **생활** 탭: 입문 과제, 오늘의 모험 목표·주간 도전·이벤트, 오늘 할 일과 "걸어가기"(길 안내), 활동(채집·낚시·던전)과 작업대, 마을 가꾸기, 내 상점, 인연, 탈것, 도감.
- 걷기: 방향키·WASD·땅 클릭(터치는 가상 패드). Enter = 길드 거래, E = 말걸기·채집·낚시·던전.

## 구성

| 위치 | 내용 |
|---|---|
| `packages/engine` | 순수 TypeScript 시장 엔진: 시드 기반 가격(일 단위 종가 + 15분 슬롯 일중 경로), 이벤트(공시·소문·여진), 시장 국면, 분기 배당, 포트폴리오·예약 주문·대출 규칙, 판타지 달력(건국력) |
| `apps/web` | React 19 + Vite + Tailwind v4 + Zustand(persist). 캔버스 월드, 거래·소식·생활·자산·시세 UI, 미니게임·던전·인연 화면 |
| `apps/server` | 2단계 서버 뼈대(개발용): 서버 시세 체결·정산·순위, 토큰 해시·요청 제한·복구 코드 등. 웹의 서버 모드는 개발 빌드에서만 보입니다 |
| `apps/web/art-source` | 소유자가 만든 일러스트 원본(히로인·던전 몬스터·길드). 제작 가이드와 프롬프트는 각 폴더의 `README.md` |
| `apps/web/scripts` | 일러스트를 게임용 WebP로 바꾸는 도구(`prepare-npc.py`, `prepare-monsters.py`, Pillow·numpy·scipy 필요) |

## 핵심 규칙 (요약)

- **시간:** 하루 = 현실의 하루, 한국 시각 자정에 새 하루가 시작되고 시세는 하루 종일 15분마다 움직입니다.
- **시세가 바뀌는 변경은 `WORLD_VERSION`을 올리고** 골든 테스트(`packages/engine/test/world.test.ts`)를 의도적으로 갱신합니다. 일중 경로 규칙은 `INTRADAY_VERSION`입니다.
- **마나로 시세·이벤트에 영향을 줄 수 없습니다.** 활동 수입은 하루 상한(활동 합계 120)이 있고, 지출처(마을·상점·인연·탈것·장비)는 영구 소비입니다.
- **저장 호환:** persist 키 `mana-market-v1`. 새 필드는 `store.ts`의 `merge`가 기본값으로 채우고, 필드를 더하면 버전을 올립니다. 저장은 브라우저 localStorage이며 프로필의 "저장 옮기기"로 백업합니다.
- **성능:** 월드는 캔버스 한 장에 그리고, 걷는 중 프레임 간격 중앙값 ≈17ms를 e2e가 확인합니다.
- **새 대사·문구**는 `apps/web/src/copy.test.ts`의 금지 표현 검사 목록에 추가합니다.

## 배포

웹은 정적 파일입니다. `npm run build`가 만드는 `apps/web/dist`를 정적 호스팅(Cloudflare Pages, Vercel, Netlify 등)에 올리면 되고, 서버·환경 변수는 필요 없습니다(서비스 워커로 오프라인에서도 열립니다).
서버(`apps/server`)는 인증·DB·HTTPS가 없는 개발용이라 **공개 배포하지 않습니다.**

## 에셋

코드와 도트 그래픽(월드·캐릭터·소품·몬스터 일부)은 저장소 안에서 생성됩니다. 히로인·던전 몬스터·길드 일러스트는 소유자가 제공한 이미지이므로, 재사용 전에 소유자에게 확인해 주세요.
